# Punto Barrio — Frontend

Interfaz administrativa del sistema Punto Barrio, creada con React, TypeScript, Tailwind CSS y Vite.

## Desarrollo

```bash
npm install
npm run dev
```

Crea un archivo `.env` a partir de `.env.example` y configura `VITE_API_URL`.

## Render

- Tipo: Static Site
- Build Command: `npm ci && npm run build`
- Publish Directory: `dist`
- Variable: `VITE_API_URL=https://TU-BACKEND.onrender.com/api`
